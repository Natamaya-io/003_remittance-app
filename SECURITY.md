# Security Checklist

- Ubah seluruh password default saat instalasi.
- Gunakan database user khusus dengan izin minimum.
- Jangan menyimpan `.env` pada repository publik.
- Gunakan HTTPS pada server produksi.
- Batasi file upload dan lakukan malware scanning.
- Lakukan backup database harian dan uji restore.
- Tinjau audit log secara berkala.
- Data beneficiary termasuk data sensitif; terapkan least privilege dan retensi data.
- Kurs eksternal hanya untuk referensi, bukan settlement final.
