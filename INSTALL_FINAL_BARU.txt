REMMITANCE APP FINAL - INSTALASI BARU
=====================================

NAMA FOLDER PROJECT:
AplikasiRemmitance

NAMA DATABASE:
AplikasiRemmitance

1. Extract folder AplikasiRemmitance ke:
   C:\xampp\htdocs\AplikasiRemmitance

2. Jalankan Apache dan MySQL pada XAMPP.

3. Buka phpMyAdmin: http://localhost/phpmyadmin

4. Import file:
   database/AplikasiRemmitance.sql
   File SQL ini otomatis membuat dan memilih database AplikasiRemmitance.

5. Pastikan file .env berisi:
   APP_URL=http://localhost/AplikasiRemmitance/public
   DB_DATABASE=AplikasiRemmitance
   DB_USERNAME=root
   DB_PASSWORD=

6. Buka aplikasi:
   http://localhost/AplikasiRemmitance/public

7. Login seperti pada aplikasi sebelumnya.

8. Buka menu Entropy-TOPSIS.
   Dataset Transaksi Sukses 2024 sudah berada pada tabel entropy_topsis_* dan terpisah dari transaksi/report aplikasi utama.

CATATAN:
- Jangan menggunakan database fable_remitops untuk instalasi ini.
- Jangan rename folder AplikasiRemmitance setelah instalasi, kecuali APP_URL dan path hardcoded juga diubah.
- File metadata macOS ._* sudah dibersihkan dari paket ini.
