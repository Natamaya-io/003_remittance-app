FABLE REMITOPS - HOTFIX TAMPILAN REPORT HARIAN
Tanggal: 09 Agustus 2026

Masalah:
Halaman /reports berhasil dibuka, tetapi kartu Bulan/Tanggal/Tim tampil seperti teks biasa.
Penyebabnya bukan database dan bukan data report. View report menggunakan class CSS baru
(report-month-card, report-hierarchy-note, report-global-search, dll.) yang belum memiliki stylesheet.

Perbaikan:
1. Menambahkan public/assets/css/reports.css
2. Memuat reports.css dari app/Views/layouts/app.php
3. Mengubah versi cache CSS app.css dan fx-idr-board.css agar browser mengambil file terbaru.

MySQL:
Tidak ada perubahan database. Tidak perlu menjalankan ALTER/UPDATE/IMPORT SQL.

Setelah menyalin file:
1. Restart Apache (opsional, tetapi disarankan).
2. Buka /reports.
3. Lakukan hard refresh: Ctrl+F5.
4. Jika masih tampilan lama: Ctrl+Shift+R atau hapus cache browser untuk localhost.
