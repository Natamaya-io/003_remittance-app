FABLE REMITOPS — INSTALASI XAMPP

A. PEMBARUAN APLIKASI LAMA
1. Backup folder C:\xampp\htdocs\AplikasiRemmitance dan database AplikasiRemmitance.
2. Ekstrak source final ke C:\xampp\htdocs\AplikasiRemmitance.
3. Pertahankan file .env lama apabila konfigurasi database sudah benar.
4. Di phpMyAdmin pilih database AplikasiRemmitance, lalu import:
   database\update_existing_database.sql
5. Aktifkan extension pdo_mysql, zip, dom, curl, openssl pada C:\xampp\php\php.ini.
6. Restart Apache dan MySQL.
7. Buka http://localhost/AplikasiRemmitance/public/system_check.php
8. Klik Lengkapi Tabel Modul apabila masih ada tabel berstatus GAGAL.
9. Buka http://localhost/AplikasiRemmitance/public/

B. INSTALASI BARU
1. Import database\install_all.sql melalui phpMyAdmin.
2. Periksa file .env.
3. Buka http://localhost/AplikasiRemmitance/public/
4. Login: superadmin / Password123!

CATATAN
- Gunakan Apache dan MySQL XAMPP. Jangan menjalankan php -S dari VS Code.
- Report Harian dan Transaksi disimpan pada tabel yang berbeda dan tidak saling memasukkan data.
- Upload XLSX membutuhkan ekstensi ZIP dan DOM aktif.
- File XLS binary lama perlu disimpan sebagai XLSX untuk dijadikan input. Output transaksi tetap dapat didownload sebagai XLS legacy.
