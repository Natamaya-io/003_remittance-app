AplikasiRemmitance - Revisi Alur Transaksi BRI & BNI

ALUR UTAMA
Menu Transaksi sekarang menampilkan dua pilihan:
1. Bank BRI
2. Bank BNI

BANK BRI
Tahap 1 : Input / Import Template (file Excel atau copy-paste)
Tahap 2 : Bentuk tabel sesuai format BRI
Tahap 3 : Hapus tanda baca pada ISI data. Nama/header kolom tetap utuh.
Tahap 4 : Download Excel XLSX/XLS

BANK BNI
Tahap 1 : Copy-paste data dari Excel
Tahap 2 : Bentuk tabel preview
Tahap 3 : Simpan batch dan buat Form Kiriman Uang BNI
Tahap 4 : Preview / Cetak

Halaman cetak BNI menyediakan:
- Cetak Form Lengkap
- Cetak Isian Saja (untuk formulir BNI yang sudah tercetak)

CATATAN DATABASE
Aplikasi otomatis membuat tabel bni_transaction_batches dan bni_transaction_rows ketika fitur BNI pertama kali dibuka.
Jadi pada XAMPP default tidak wajib import SQL manual.
Jika ingin membuat tabel lebih dahulu, import UPDATE_TRANSAKSI_BANK_BNI.sql.

INSTALASI
1. Backup folder C:\xampp\htdocs\AplikasiRemmitance
2. Extract ZIP ini.
3. Copy folder AplikasiRemmitance ke C:\xampp\htdocs\
4. Replace file lama.
5. Restart Apache.
6. Tekan Ctrl+F5 di browser.

URL utama:
http://localhost/AplikasiRemmitance/public/transactions
