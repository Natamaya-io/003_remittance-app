PANDUAN UPDATE PERHITUNGAN ENTROPY + TOPSIS 2024
==============================================

TUJUAN
- Mengganti perhitungan lama pada modul SPK saja, tanpa menghapus tabel transaksi operasional,
  invoice, laporan operasional, akun pengguna, atau dokumen lain.
- Menggunakan 3.473 transaksi sukses + 174 catatan refund terdeduplikasi
  hanya untuk empat perusahaan penelitian pada periode September–Desember 2024.
- Metode Entropy: K=X/max(X), a=K/sum(K), E, D=1-E, W=D/sum(D).
- TOPSIS: Rij, Yij, ideal (+/-), jarak Euclidean, preferensi, ranking.

CARA UPDATE INSTALASI SUDAH ADA (XAMPP)
1. WAJIB: Export database saat ini dari phpMyAdmin sebagai cadangan.
2. Backup folder C:\xampp\htdocs\AplikasiRemmitance\ (termasuk .env, storage, public/uploads).
3. Salin/perbarui file PHP aplikasi dari ZIP ini; PERTAHANKAN .env aktif dan file upload milik Anda.
4. Buka phpMyAdmin -> pilih database `aplikasiremmitance` yang sudah ada -> tab Import.
5. Impor HANYA: database/UPDATE_DATABASE_ENTROPY_TOPSIS_2024.sql
   (atau file SQL bernama sama yang dikirim terpisah).
   Jangan impor AplikasiRemmitance.sql FULL ke database yang sudah aktif.
6. Pastikan SQL selesai tanpa error; jika error, jangan lanjut sebelum dicari penyebabnya.
7. Buka modul Analisis -> Hasil Akhir; pastikan hanya ada satu run final.
8. Buka Data Penilaian untuk melihat C1-C6 yang dihitung otomatis.
9. Bila Anda mengunggah Excel baru ke aplikasi, sistem akan menghapus run tersimpan lama.
   Buka Perhitungan -> Simpan Perhitungan untuk membuat run berdasarkan sumber aktif terbaru.
