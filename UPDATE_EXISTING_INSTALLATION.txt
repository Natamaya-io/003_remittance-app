UPDATE INSTALASI LAMA TANPA MENGHAPUS DATA

1. Backup database melalui phpMyAdmin.
2. Backup C:\xampp\htdocs\AplikasiRemmitance.
3. Ekstrak paket final dan timpa file aplikasi lama.
4. Jangan menimpa .env apabila konfigurasi database lama sudah benar.
5. Buka http://localhost/AplikasiRemmitance/public/system_check.php
6. Klik "Lengkapi Tabel Modul".
7. Pastikan tabel document_template_types, document_templates,
   invoice_template_documents, si_templates, si_documents,
   dan si_document_items berstatus OK.
8. Restart Apache dan MySQL.
9. Login: superadmin / Password123!
10. Buka menu Dokumen & Template dan Report Harian.

Untuk instalasi kosong, impor database/install_all.sql.
