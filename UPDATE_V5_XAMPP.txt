FABLE REMITOPS V5 - CARA UPDATE DI XAMPP

1. BACKUP folder aplikasi dan database.
2. Ekstrak folder AplikasiRemmitance ke C:\xampp\htdocs\AplikasiRemmitance.
3. Pertahankan file .env lama atau sesuaikan koneksi database.
4. Di phpMyAdmin, pilih database AplikasiRemmitance.
5. Jalankan database/migration_upgrade_v4.sql bila V4 belum pernah dipasang.
6. Jalankan database/migration_upgrade_v5.sql.
7. Pastikan extension PHP berikut aktif: pdo_mysql, zip, dom, mbstring, curl.
8. Restart Apache dan MySQL.
9. Buka http://localhost/AplikasiRemmitance/public/system_check.php.
10. Setelah semua status hijau, login dan uji import transaksi/report pada salinan data.

CATATAN KURS
- FX_PROVIDER=auto memakai ExchangeRate-API bila FX_API_KEY diisi.
- Tanpa API key, sistem fallback ke Frankfurter.
- Kurs yang ditampilkan adalah kurs referensi provider publik dan mengikuti interval update provider/cache.
