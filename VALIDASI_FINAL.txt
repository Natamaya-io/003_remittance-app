VALIDASI FINAL - AplikasiRemmitance (Report 2024 + Actual)
========================================================

1. ISOLASI MODUL ANALISIS
AnalysisController, SpkImportService, SpkAnalysisService, dan EntropyTopsisEngine
hanya menggunakan tabel spk_* untuk perhitungan penelitian.
Tidak ada pembacaan data analisis dari transactions, report_rows, companies,
invoices, atau complaints.

2. SUMBER DATA PENELITIAN
- Report Sukses 2024 : sumber C1-C5.
- Actual LIST MT199  : sumber refund C6, hanya sheet REFUND BNI + REFUND BRI.
- Daily Update Tiara : TIDAK digunakan dalam perhitungan.

3. PERIODE
- P1: 1 September 2024 - 31 Oktober 2024.
- P2: 1 November 2024 - 31 Desember 2024.

4. KRITERIA
C1 Benefit - pertumbuhan jumlah transaksi.
C2 Benefit - pertumbuhan transaksi per hari aktif.
C3 Benefit - pertumbuhan cakupan negara.
C4 Benefit - pertumbuhan cakupan bank/SWIFT.
C5 Benefit - pertumbuhan keragaman mata uang.
C6 Benefit - tingkat transaksi tanpa refund P2.

5. METODE
Entropy mengikuti modul PDF:
Kij = Xij / max(Xj) untuk seluruh kriteria benefit,
aij = Kij / Sum(Kij), Ej, Dj = 1-Ej, Wj = Dj/Sum(Dj).
TOPSIS: Rij, Yij, A+/A-, D+/D-, Vi, ranking.

6. HASIL DATA BAWAAN
Ranking seed berdasarkan dua file bawaan:
1. PT JURITA AGROTAMA INDONESIA
2. PT KAIROS SINERGI INDONESIA
3. PT FABLE TEKNOLOGI NUSANTARA
4. PT GEMA SAPTA BINTANG

7. RUNTIME
Upload XLSX membutuhkan extension PHP ZIP dan DOM aktif pada XAMPP.
